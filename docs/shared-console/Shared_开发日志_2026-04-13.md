# Shared 开发日志（2026-04-13）

## 背景
- 本轮在 Shared Console 渠道管理 card-first 改造后继续进行线上联调。
- 用户反馈两个现象：
  1. 渠道轮询后疑似未映射到 OpenClaw 实例配置，聊天无返回。
  2. 点击实例详情“复制 UI 链接”后在新窗口打开，提示：
     - `Control UI assets not found. Build them with \`pnpm ui:build\`...`

## 现场检查与结论

### 1) 渠道轮询映射状态
- 检查 `/api/model-channels` 与 `/api/instances`，确认实例 `crewclaw-1` 映射到 `hyb-rr`。
- 检查实例配置文件：
  - `/www/openclaw/shared-instances/crewclaw-1/config/openclaw.instance.json5`
- 结论：
  - `models.providers` 已包含 `hyb-1` / `hyb-2`。
  - `agents.defaults.model` 已写入 `primary + fallbacks + round-robin`。
  - 渠道轮询映射已落盘并生效，不是“未写入配置”的问题。

### 2) UI 链接报错（assets not found）
- 在服务器检查发现 `ui/dist` 不存在（实际运行依赖构建产物到 `dist/control-ui`）。
- 执行：
  - `pnpm ui:build`
- 构建成功后生成：
  - `/www/openclaw/repo/dist/control-ui/index.html`
- 复查实例 UI 代理：
  - `GET /api/instances/crewclaw-1/ui/` 返回 `200`，可返回 Control UI HTML。

### 3) 过程中的短暂 502
- 曾出现：
  - `{"ok":false,"error":{"type":"proxy_upstream_failed","message":"fetch failed"}}`
- 结合健康状态与复测结果判断为：
  - 实例端口可达性短暂波动（重启/切换窗口期）导致的上游反代失败。
- 后续复测已恢复，实例 UI 可正常打开。

## 最终验证结果
- 实例 1 的 UI 链接可打开。
- Control UI 可进入并完成模型对话。
- 用户侧确认“UI 界面打开了，而且模型对话也有了”。

## 操作沉淀（建议）
1. 每次部署后固定执行一次 UI 构建：
   - `pnpm ui:build`
2. 将 `dist/control-ui` 可用性纳入值班台上线前检查项。
3. 若再出现 `proxy_upstream_failed`，优先按顺序排查：
   - 实例进程是否 running
   - 实例端口是否可达
   - 容器桥接网络是否可达
   - 最后再看前端缓存与浏览器侧问题
